# Drellion Nexus

Drellion Nexus is a public, vocal-first music production application designed around two workflows:

- **AI Auto** — Vocal & Lyrics → Reference → Sounds → Preview → Build → Master
- **Custom Studio** — non-destructive multitrack editing, mixing, automation, AI-assisted arrangement, and mastering.

## Core principle

The user's vocal drives melody, phrasing, timing, and musical compatibility. A reference track guides production direction — groove, structure, energy, dynamics, stereo image, and tonal character — while Drellion generates a new instrumental rather than copying the reference recording, exact beat, melody, samples, or hooks.

## Public repository / large assets

The application source is public. Large sound libraries, model packs, installers, and other distributable binary assets are **not committed to Git history**. They are versioned separately and, when redistribution rights permit, distributed as release assets or downloadable packs.

The repository does not currently declare an open-source license. Public visibility does not by itself grant redistribution/modification rights; a license will be selected deliberately before the 1.0 release.
